# Fetching Data from PokeAPI with React 🚀

This repository contains the code and examples I created while following the [Learn to Consume Your First API with This Video! (PokeAPI React/JS) | VTUBER (ESP)](https://www.youtube.com/watch?v=y9VisC_upk4) tutorial.

## 📖 Description

Do you want to learn how to fetch data from the PokeAPI using React and JavaScript? 🚀 In this video, I learned step-by-step how to make requests to a server, handle the response, and map the data in a React component to dynamically display Pokémon information.

## 🔥 What I Learned:

- ✅ **How to make a fetch request to an API using JavaScript.**
- ✅ **How promises and async/await work in HTTP requests.**
- ✅ **How to receive and transform data from PokeAPI.**
- ✅ **How to render Pokémon data in a React component.**

## 🎯 Why I Followed This Tutorial

- 🧑‍💻 To get hands-on experience with **fetching data from APIs in React.**
- 💡 To **improve my understanding of async/await and HTTP requests.**
- 🚀 To **enhance my frontend development skills and API integration knowledge.**

## 📌 Technologies Used

- **JavaScript**
- **Fetch API**
- **useEffect**
- **useState**
